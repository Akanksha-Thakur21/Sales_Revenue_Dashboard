# Sales & Revenue Dashboard using Power BI

## Project Overview
This project is an interactive Sales & Revenue Dashboard built using Power BI.  
The dashboard helps analyze sales performance, profit, costs, customer orders, and country-wise revenue using different visualizations and KPI metrics.

## Features
- Total Sales KPI
- Total Cost KPI
- Profit Analysis
- Total Orders Tracking
- Revenue Trend Analysis
- Country-wise Sales Analysis
- Device Type Order Distribution
- Category-wise Cost Analysis
- Interactive Filters and Slicers

## Tools Used
- Power BI
- Excel Dataset

## Dashboard Visuals
- KPI Cards
- Line Chart
- Bar Chart
- Pie Chart
- Map Visualization
- Slicers
## KPIs Used
- Total Sales
- Total Cost
- Profit
